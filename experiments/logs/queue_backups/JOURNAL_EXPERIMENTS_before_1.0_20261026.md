## 0. 路线与约定

**论文路线**（2026-10-21 用户决定）：

1. **轻量化 ApproxDA**（LightViT 加 C=64 decoder）：4 个数据集、3 个 seed 下精度持平，开销降到 1/9 – 1/3。单独不足以成为创新点，作为期刊的附加贡献（§1）。
2. **主攻方向：让 dual attention 真正起作用**，目标是解决需要上下文才能判断的“整块器官被认错”（胃↔脾、左右肾等，§3 – §4），并在有这类问题的大数据集（AMOS）上验证。这部分单独投一篇会议。
3. 如果 2 成功：先投会议，再把 1 和 2 合起来做主推的期刊。§2 的诊断（attention 从没被训练、提升来自卷积通路、GCS 主要是噪声）作为 2 的动机。

**实验约定**：

- 新功能全部是可选参数，默认关闭。默认路径必须和论文结果逐位一致，每次改代码后用 Fig. 3 那张切片验证（case0032 第 131 层，Dice 96.44）。
- 各数据集沿用 workshop 协议：
  - Synapse：灰度，SGD lr 0.01，300 epoch，224；
  - CVC：灰度，Adam 1e-3，500 epoch，256；
  - ISIC：RGB，SGD，50 epoch，256，drop_last；
  - ACDC：同 Synapse。
  - 统一 batch 24，取最后一个 epoch，不用 test 选 checkpoint。
- **seed**：主表统一用 1234 / 0 / 1（2026-10-19 用户决定）。早期参照用过的 2345 / 3456 结果保留，用于估计 seed 方差。
- **优化器**：attention 不单独换 Adam（§2.4，AdamW 激活 attention 会变差）。主表保持 SGD，与已发表的 Synapse 协议可比。
- **增强**：主表沿用标准 TransUNet 增强（含镜像）。增强问题只放在分析小节（§3.3）。会议论文是否改用保持朝向的增强，取决于位置感知实验的结果。
- 单 seed 结果只用于筛选。Synapse 上 ApproxDA 5 个 seed 的标准差是 1.16（81.63 / 78.69 / 79.05 / 80.19 / 79.45），DA 是 0.52，所以差距在约 1.5 以内的单 seed 结果都分不出高低。

### 1.4 为什么用 ApproxDA block（轻量档上的 block 消融，2026-10-21 完成）

同一个 LightViT-T + C64 backbone，Synapse，seed 1234 / 0 / 1。“配对”指与 ApproxDA 在同一 seed 下的差值。

| 变体 | 参数 | GFLOPs（其中 attention） | 训练时间 | 各 seed | 均值 ± std | HD95 | 配对差（p） |
|---|---|---|---|---|---|---|---|
| ApproxDA block（主模型） | 12.04M | 6.64（0.01） | 约 43 min | 79.40 / 80.55 / 80.40 | 80.12 ± 0.63 | 23.96 | – |
| DA 等价 block（M=112、r=0、G=1、固定融合 = DANetHead） | 10.65M | 7.90（0.99） | **约 94 min** | 79.76 / 80.07 / 80.04 | 79.96 ± 0.17 | 23.54 | −0.16（0.60） |

| 只留卷积（attn_off，对照） | 10.4M（实际用到的） | 6.63 | – | 79.33 / 80.70 / 80.49 | 80.17 ± 0.74 | 25.23 | +0.06（0.47） |

- 各器官均值（主动脉 / 胆囊 / 左肾 / 右肾 / 肝 / 胰腺 / 脾 / 胃）：
  - ApproxDA：88.7 / 66.2 / 81.9 / 79.6 / 94.9 / 61.4 / 89.1 / 79.1；
  - DA 等价：88.6 / 63.2 / 80.7 / 78.1 / 94.8 / 61.4 / 90.5 / 82.4；
  - 不加 block：87.5 / 62.3 / 81.2 / 78.7 / 94.7 / 58.5 / 88.8 / 79.3（胰腺 −2.9、胆囊 −3.9）。
- **结论（论文一可用）**：
  1. **block 是必要的**：不加 block 时 3 个 seed 都更低，平均 −1.25，HD95 变差 3.6。降幅比 ViT-B 上小（单 seed −5.4），可能是因为精简 decoder 的 ReduceBlock 本身已经对 skip 做了残差卷积精修。

## 2. 诊断：dual attention 实际上没有起作用

### 2.1 α / γ 死锁（SGD 下 attention 从没被训练）

PAM 输出 `α·E + x`，α 初始化为 0（DANet、DA-TransUNet、ApproxDA 都是这样）。

| 模型 | α | ‖输出 − 输入‖/‖输入‖ | α 置 0 后改变标签的像素 |
|---|---|---|---|
| Synapse c16 M=112（workshop 主结果，SGD） | 1e-4 – 1e-3 | 1e-6 – 1e-4 | 0.0002% |
| T4 旧模型（legacy block） | 1e-5 – 2e-3 | 1e-6 – 6e-5 | ≤ 0.0002% |
| CVC c16 M=8 / M=128（Adam） | 5e-41 / 0.2 | 0 / 2 – 4% | 0% / 0.046% |

- 原因（`scratchpad/alpha_grad.py`）：α = 0 时，Q、K、V、P 的梯度恰好为 0；|dL/dα| ≈ 4e-6 – 4e-5，而 decoder 卷积约为 0.29。
- 权重漂移（`scratchpad/init_drift_all.py`）：看训练后的 max|w| 与默认初始化上界 b 之比。只受 weight decay 作用时，各权重按同一比例缩小，约 0.87。
  - 默认 PAM 的 q / k / v / proj：0.84 – 0.86，从没被梯度学过；同一 block 的卷积为 0.87 – 2.8。
  - tf 风格 PAM：0.86 – 0.89，LayerScale γ 停在 0.1；tf 加门控：最大 1.47，只学到一部分。
  - 只有去掉 identity 时 attention 才真正学习（最大 10.4），但 Dice 更低（§2.4）。
- 系数（最后一个 epoch，bottleneck / skip）：
  - DA 的 PAM 系数都 ≈ 0；CAM 在 Synapse 是 0.12、CVC 0.23 – 0.36、ISIC ≈ −0.02；
  - ApproxDA cam 模型的 CAM 在 Synapse 是 0.11、CVC 0.35；ISIC 为 −0.09 至 −0.19。
- bottleneck block 位于 patch embedding 之后、ViT 之前（和 DA 原文 Fig. 1 一致），没有外层残差，ViT 的输入全部经过 768→48→768 的压缩。

## 3. 错误分析：长距离上下文该修什么

### 3.1 错误组成（`scratchpad/error_decomp.sh`，Synapse 测试集合并像素的 9×9 混淆矩阵）

| 模型 | 漏检（器官→背景） | 误检（背景→器官） | 器官↔器官 | 其中整块认错（> 20 px 或该切片里没有这个器官） |
|---|---|---|---|---|
| 基线 ViT-B | 40.8% | 46.8% | 12.4% | **8.9%** |
| 只留卷积 | 37.0% | 50.2% | 12.8% | 9.2% |
| 不加 block | 37.6% | 42.6% | 19.8% | **16.2%** |
| 去掉 ViT | 49.3% | 35.3% | 15.4% | 12.1% |
| 轻量档 | 58.2% | 29.1% | 12.6% | 9.4% |
| AdamW 激活的 attention | 38.4% | 49.7% | 11.9% | 8.8% |
| 不做镜像增强 | 41.9% | 45.7% | 12.4% | 8.6% |

（百分比是占全部错误像素的比例。整块认错用 `scratchpad/confusion_far.py` 计算：每个混淆像素到同一切片里最近的、被预测成的那个器官的真值像素的距离。）

- 约 87% 的错误是器官与背景之间的边界或范围错误，属于局部问题。
- 器官之间的混淆有 70 – 80% 是整块认错，约占全部错误的 9%，主要是胃→脾、左右肾互认、胃 / 脾→肝。这些都需要相对位置才能分清。
- 减少整块认错的是 skip block 的卷积（去掉后 8.9% → 16.2%）和 ViT（去掉后 → 12.1%）。attention 无论没被训练，还是用 AdamW 训练起来，都没有进一步减少。

### 3.2 整块认错集中在少数病例

- **case0003** 在基线、不做镜像增强、轻量档里分别占全部整块认错的 61% / 58% / 59%。基线中胃→脾有 93% 来自它，左右肾互认几乎全部来自 case0003 和 case0029（或 case0025）。其次是 case0032（胃→脾）和 case0001（脾→肝）。
- 含义：这类错误主要来自一两个不典型的病例（case0003 有 198 层，视野很大），而训练集只有 18 例。Synapse 上这个指标被单个病例主导，方差很大，**结论需要更大的数据集（AMOS）来验证**。

### 3.3 左右肾混淆与镜像增强

- 所有模型都有左右肾互认（2 – 9%），集中在 case0003、case0029。12 个测试病例的朝向一致，数据本身没有问题。
- 根源是增强：`random_rot_flip` 先随机 90° 旋转，再**必定**沿某个轴翻转，而且不交换左右标签。一半的训练图是镜像，左右手性被打乱。
- 去掉镜像（`--aug rot_only` / `small_rot`，基线配置，单 seed）：

| 增强 | Dice / HD95 | 左肾 | 右肾 | 胃 | 左右混淆 |
|---|---|---|---|---|---|
| 默认 | 81.63 / 23.73 | 81.2 | 81.8 | 82.7 | 6.9 / 2.1% |
| rot_only | 81.05 / 18.32 | 87.4 | 83.4 | **76.8** | **0 / 0%** |
| small_rot | 80.63 / **13.48** | 87.0 | 84.0 | **76.6** | **0 / 0%** |

  - 左右混淆完全消失，但胃掉约 6 分：胃→脾的整块认错翻倍（3.5% → 7.4%，§3.1），说明镜像帮助区分胃和脾。只要做 90° 旋转，任何翻转都等价于左右镜像加旋转。
- 后处理诊断（`test.py --lr_post`：按主动脉两侧重新分配左右肾，没有可调参数，作用在真值上不改动任何体素）：6 个模型的 Dice 提升 0.74 – 1.85，HD95 下降 6 – 11；基线 3 seed 均值 79.79 → 81.27。它只作为诊断证据（左右混淆约损失 1.5 Dice），不能进主表，因为是看过测试集后设计的。
- 报告方式（2026-10-19 用户决定）：主表用标准增强；增强问题作为分析小节。已有文献：TotalSegmentator 去掉了镜像；ToothFairy2 只关左右方向的镜像，并发现全部关掉更差；nnU-Net issue #80 指出 nnU-Net 不会自动处理这个问题。

### 3.4 AMOS 上的错误来源（`analyze_error_sources.py`，small_rot 基线 seed 1234，Va-CT 100 例，2026-10-21）

按器官统计假阳性 + 假阴性，共 46.2 L。器官互认的错误会算两次：一次是一个器官的假阳性，一次是另一个器官的假阴性。

- **到真值表面的距离**：≤2 mm 占 48.9%，2 – 5 mm 占 23.0%，5 – 15 mm 占 17.4%，>15 mm 占 10.4%，预测了不存在的器官占 0.3%。即约 72% 在边界 5 mm 以内。假阳性与假阴性大致各半（47.6% / 52.4%）。
- **器官上下两端**：12.3% 的错误体积落在真值或预测中没有该器官的层面上，即器官的起止层数不对。比例最高的是胆囊 38%、膀胱 25%、前列腺 / 子宫 24%、胃 17%。
- **224 分辨率的上限**：把真值按测试流程缩到 224 再用最近邻放大回去，15 个器官的平均 Dice 只有 **95.46**。光是分辨率就占了约 4.5 个点（基线 81.83 离 100 差 18.2 个点）。肾上腺的上限只有 88.0 / 88.6，食管 92.9，下腔静脉 95.0，十二指肠 95.3。
- **对平均 Dice 拖累最大的是小、细、低对比度的器官**：左右肾上腺共 4.3 个点、十二指肠 2.1、胰腺 1.7、前列腺 / 子宫 1.6、胆囊 1.6、食管 1.5，合计约 13 个点。肝、肾、脾、主动脉合计约 2.1 个点。错误体积最大的是肝（11.1 L）和胃（9.7 L），但它们的 Dice 本来就高，对平均 Dice 影响小。
- 结论：剩下的错误主要来自
  1. 边界精度，其中一部分受 224 输入分辨率限制；
  2. 小器官和低对比度的边界（十二指肠 / 胰腺、胃 / 肠）；
  3. 器官的起止层面（2D 模型没有层间信息）；
  4. 远处错误约 10%，其中器官互认约 2.5%，背景被认成器官约 7%。
  
  切片内的长距离 attention 只能处理最后一类中的一部分。更有针对性的方向是更高的输入分辨率（轻量档省下的计算正好可以用在这里）和层间上下文（2.5D）。

## 4. 进行中：让 attention 解决整块认错（会议论文）

**假设**：现在的 PAM 修不了整块认错，原因可能有五点：

1. 优化：加法融合在 α=0 时死锁，用 AdamW 激活后又会覆盖原有特征；
2. 没有位置信息，Q / K 只由内容算出；
3. 放在低层、窄通道的 skip 上，而认错是器官级判断；
4. 像素级损失对认错和边界偏移一视同仁；
5. 数据少，而且错误集中在不典型病例上。

### 4.1 OR 式融合（`--pam_fusion max|relu_add|lse`，只用于 DANet 式 PAM）

- 三种形式：$y=\max(x,E)$、$y=x+\mathrm{ReLU}(E)$、$y=\log(e^x+e^E)$。都以 x 为下限（conv5a 之后 x ≥ 0），不用 α。
- 梯度检查：默认加法融合下 attention 权重的梯度恰好为 0；OR 融合从第一步就有梯度（conv_D 约 5e-4 – 8e-4，proj_r 约 1e-2 – 2e-2）。
- 排队（轻量档，seed 1234）：max + SGD（只换融合方式，能否在标准协议下训练起来）；max / relu_add / lse + AdamW（对照加法 + AdamW 的 78.12 ± 1.10）。
- max + SGD（2026-10-21 完成）：Dice / HD95 78.53 / 26.38，同 seed 的轻量档默认为 79.40 / 22.37（3 个 seed 为 79.40 / 80.55 / 80.40，均值 80.12 ± 0.63）。比 3 个 seed 中最低的还低 0.87，倾向于变差，但只有一个 seed。

### 4.2 位置感知 attention

- A `--pam_relpos`：类似 Swin 的相对位置偏置，$\mathrm{softmax}(q_i^\top k_j+b_{\delta(i,j)})$。低秩路径计算 $(Q^\top K+B)P$。与手算一致（误差 0 / 1e-7）。需要显式构造 N×N 的偏置矩阵，所以用 M=28。
- B `--pam_abspos`：把归一化的全局坐标拼到 Q / K 的输入上。
- C `--coord_gate`（第三个分支）：Coordinate Attention 改成残差门控，$y=x\odot(1+\tanh(a_h(i)+a_w(j)))$，零初始化，初始时是恒等映射（原版 sigmoid 门控在 max 融合下会被忽略）。
- 开销最多增加 0.014M 参数、0.06 GFLOPs；新参数都有梯度；默认路径不变。
- 预判：L/R 问题用增强就能解决；胃↔脾需要关系信息，A 更对症；B 与 ViT 已有的绝对位置编码重复。标准增强会把 8 种朝向打乱，位置信息因此失效，所以这组实验用 small_rot。
- 排队（轻量档，small_rot，M=28，seed 1234）：P0 默认，PM 仅 max，PA max + 相对位置，PB max + 绝对坐标，PC max + 相对位置 + coord gate。指标：Dice、整块认错比例（重点看胃↔脾和 case0003）。
- P0（默认 block，attention 未训练，权重 0.86 倍；2026-10-21 完成）：Dice / HD95 **80.46 / 11.03**。轻量档默认增强为 79.40 / 22.37；P0 和它的唯一实质区别是增强，因为 attention 没被训练，M 对输出没有影响。
  - 整块认错 12.92%（默认增强 9.42%），其中左右肾互认降为 **0**，但胃→脾从 2.98% 升到 **9.95%**；case0003 占 61%。ViT-B 上去掉镜像也是同样的规律（§3.3）。
  - 所以 P 系列要解决的就是胃→脾：PM / PA / PB / PC 都和 P0 比，看胃→脾能否从 9.95% 降下来，同时左右肾互认保持为 0。
- PM / PA / PB 结果（2026-10-21 19:20，单 seed）：

| 配置 | Dice / HD95 | 整块认错 | 左右肾互认 | 胃→脾 | 测试时关掉 attention |
|---|---|---|---|---|---|
| P0 默认 block | 80.46 / 11.03 | 12.92% | 0 | 9.95% | （attention 本来就是恒等） |
| PM max | 81.24 / 10.17 | 8.23% | 0 | 5.02% | 8.25% / 5.06%，合并 Dice 83.36 → 83.39 |
| PA max + 相对位置 | 80.58 / 9.64 | 12.52% | 0 | 9.80% | |
| PB max + 绝对坐标 | 81.37 / 10.40 | 7.86% | 0 | 4.76% | 7.72% / 4.59%，合并 Dice 82.84 → 82.80 |

  - **位置模块根本没有被训练**：相对位置偏置最大 1e-4，绝对坐标通道的权重只是初始值乘以约 0.78（weight decay）。attention 权重最大只有 0.9 – 1.02 倍（M=112 的 max + SGD 是 1.3 – 1.7 倍）。max 融合下 E 在约 30% 的元素上胜出，但增量只有 |x| 的 1 – 7%（`scratchpad/max_win.py`）。
  - **测试时关掉 attention，结果几乎不变**，所以 PM / PB 相对 P0 的胃→脾减半不是 attention 的贡献。PA 在功能上和 PM 几乎一样，胃→脾却是 9.80% 对 5.02%：在 Synapse 上，这个指标在等价配置之间就能相差约 5 个点（case0003 占 56 – 64%）。
  - 结论：
    1. Synapse 单 seed 无法检测这个量级的效果。之前所有“某种 attention 改动让整块认错变多 / 变少”的判断，都在噪声范围内。
    2. 问题不在融合方式，而在于 SGD 下 attention 分支的梯度太弱，根本学不动；用 AdamW 能学动，但会伤精度。
    3. 唯一稳定的规律是增强：不镜像时左右肾互认为 0（5 / 5 个 run），胃→脾升到 5 – 10%（镜像时为 2 – 4%）。P0 / PM / PA / PB 实际上是“轻量档 + small_rot”的 4 次重复，Dice 均值 80.91、HD95 约 10.3，而标准增强 3 个 seed 为 80.12 ± 0.63、HD95 约 24。

- 机制：被监督的 attention 学会了，但网络没用它的输出。DA block 的结构（C/16 压缩，加上 identity 或 max 下限）让 attention 的输出可有可无，SGD 走卷积通路就够了。器官分支直接以全宽加到 block 输出上，正是为了绕开这一点。
- 已追加 AMOS 两种增强各 2 个 seed（0 / 1），确认增强的结论。

### 4.4 Context Prior 亲和监督（`--pam_affinity w`，2026-10-21 实现）

- 动机：§4.1 和 §4.2 说明，SGD 下 attention 分支拿到的梯度太弱，学不动；用 AdamW 学动了又伤精度，说明没有约束时学到的不是有用的关系。所以要直接监督 attention map。与 OCR 相比，这个方案改动最小，而且保留 DA block（用户选择“更适配我们结构”）。
- 实现（只改瓶颈 block，轻量档里在 14×14 上，窗口覆盖全图）：
  - Q / K 改由 block 输入（128 通道）映射到 32 维。原来的 Q / K 来自 C/16 压缩后的 8 通道，只有 1 个通道，logits 秩为 1，表达不了块状的同类结构。
  - 亲和矩阵 $P=\sigma(QK^\top/\sqrt{32})$，用精确的全局 attention（196×196），不做低秩投影；用行归一化的 P 聚合 V，相当于类内上下文。
  - 损失（Yu et al., CVPR 2020）：理想亲和矩阵 $A=LL^\top$，L 是 one-hot 标签平均池化到 14×14 后每个格子的类别比例；损失为 BCE(P, A) 减去按行平均的 log precision + log recall + log specificity。总损失 = 0.5 CE + 0.5 Dice + w · 亲和损失。
  - 融合用 max：§2.1 中 α 在 SGD 下停在 1e-4 – 1e-3，用 α·E + x 时监督后的分支也进不了输出。
  - 其余 block 不变。
- 验证：
  - 默认路径以及 max / relpos / abspos / cg / ViT-B 各变体的前向输出与改动前逐位相同；梯度差异与同一份代码两次运行之间的差异同量级（GPU 不确定性）。
  - 亲和路径：Q / K 梯度范数约 1（默认配置下严格为 0）；损失大小为理想 logits 1.01 < 全零 2.58 < 反向 13.9（下限不为 0 是因为边界格子是软标签）。
  - Synapse 1 epoch 冒烟测试：loss_aff 从 2.6 降到 1.68；test.py 能找到 checkpoint，权重全部对上。
- 排队（AMOS，轻量档，small_rot，M=112，26 epoch）：AFF = max + 亲和（w=1）；对照 PM = 只用 max。两者都和 AMOS small_rot 基线比。看 Dice、HD95、整块认错（`analyze_misidentification.py`），并在测试时关掉 attention，看它是否真有贡献。

### 4.5 Triple attention：像素 – 通道 – 器官（`--third_branch organ|triplet`，2026-10-21 实现）

- 动机（用户 2026-10-21）：用不同的 attention 机制（dual / triple）解决整块认错，并写进期刊。整块认错是器官级的错误（整块区域内部是一致的），像素级 attention 纠正不了，所以第三路直接建模像素 – 器官和器官 – 器官的关系，并加直接监督。
- 位置：只加在瓶颈 block 上（轻量档 14×14、128 通道），输出投影回完整宽度后加到 block 输出上，不经过 C/16 压缩。PAM / CAM 原样保留。
- 器官分支 `OrganBranch`：
  - f = 3×3 卷积（C → 64）；辅助头 1×1 卷积（64 → K）输出粗分割，用软交叉熵监督（目标是每个格子的类别比例，权重 `--organ_aux` 0.4，与 OCR 相同）。
  - 区域权重：每个像素的类别概率 p_k 按类在空间上归一化（ACFNet 式类中心）。最初按 OCR 用空间 softmax，但 300 次迭代的探测显示区域熵停在 5.17（均匀分布为 5.28），原型无法区分，因此改掉。改后有器官的类的熵在 300 次迭代内从 5.23 降到 4.30，并仍在下降。
  - 原型 f_k，质心 c_k，出现程度 m_k = mean(p_k)；器官之间的 self-attention 输入为 LayerNorm(f_k + Pos(c_k, m_k))，残差更新原型；像素 – 器官 attention 后，[f, ctx] 经 1×1 卷积、BN、ReLU 投影回 C。
  - `ablate` 只把器官上下文置零（f 通路保留），用于测试时判断贡献。
- 对照 `TripletBranch`：Triplet Attention（Misra et al., WACV 2021），三个基于旋转的门控取平均，无监督；降维、拼接和投影与器官分支完全相同，唯一的区别是 attention 机制。
- 开销（轻量档，AMOS 16 类）：器官分支 +0.12M 参数 / +0.02 GFLOPs，Triplet +0.09M / +0.018。
- 验证：
  - 默认路径以及各已有变体的前向逐位不变。
  - 器官分支在 SGD 下 300 次迭代中，位置编码、器官间 attention、像素 – 器官 attention 的梯度都在上升（q 从 2.5e-6 升到 6e-4，kv 和 rel_qkv 到 1e-2）。
  - Synapse 1 epoch 冒烟测试：两种分支的 train / test 都正常，checkpoint 能找到。
- 排队（AMOS，轻量档，small_rot，M=112，26 epoch）：ORG 器官分支；TRI Triplet 对照；FULL 亲和 PAM（max）+ 器官分支。

### 4.6 层间 attention（`--slice_attn K`，2026-10-21 实现）

- 动机（§3.4）：约 72% 的错误在边界 5 mm 内（模型的一个像素约 1.7 mm），不是感受野或卷积核不够大的问题（感受野已覆盖全图，5×5 的 MedNeXt 式 block 更差）。还缺的上下文在层间：器官起止层面的错误占 12%，肠管被认成胃约 7%，这些在相邻层里容易分清。切片内的全局关系 Transformer 已经提供了。用户决定：方法上做模型改动，不调数据、预处理和后处理。
- 实现：
  - 当前层和上下各 K 层都过同一个 2D 编码器（R50 + LightViT + 瓶颈 block）。
  - 瓶颈处当前层的 196 个 token 关注全部 (2K+1)×196 个 token，加可学习的层偏移嵌入和 token 位置嵌入；pre-norm 4 头 MHA + MLP（2 倍宽），用普通残差，不用零初始化或 LayerScale（§2.1、§2.4 中带门控的残差 attention 在 SGD 下学不动）。
  - decoder 只解码当前层，skip 只用当前层的特征。
  - K=0 是对照：同一层，只看当前层。
  - `ablate="neighbours"` 把 key 限制在当前层，用于测试时判断层间上下文的贡献；`ablate=True` 跳过整个模块。
- 数据（`datasets/dataset_slices.py`）：相邻层在体积两端截断；整个 stack 用同一组随机增强（相同随机数下，中心层和标签与 2D 流程逐位一致）。测试时 `test_single_volume(slice_ctx=K)` 先把整卷缩到 224，再逐层取 stack。
- 开销（轻量档，AMOS 16 类）：+0.16M 参数；每层 GFLOPs：K=0 为 6.72，K=1 为 11.89，K=2 为 17.07（编码器要算 2K+1 层），仍低于原版 ApproxDA。训练 1 epoch 约 4.2 分钟（与其他任务共用 GPU），26 epoch 约 1.5 – 2 小时。
- 验证：默认路径逐位不变；新模块有梯度；两种消融都会改变输出。
- 排队（AMOS，轻量档，small_rot，M=112，26 epoch）：SA1（K=1）、SA0（K=0 对照），排在 4 个多 seed 验证之前。判定标准：起止层面错误（12%）和背景→器官的远处错误（约 7%）明显下降；测试时 `ablate="neighbours"` 后结果明显变差；而且比 SA0 好。

### 4.9 方案 A：原分辨率边界细化头（`--point_refine`，2026-10-22 实现）

- 动机（§3.4）：49% 的错误在边界 2 mm 以内，模型的一个输出像素约 1.7 mm；在 224 上完全预测正确，Dice 上限也只有 95.5。用户选择从模型结构上改，并强调不能违背轻量化，所以不加通道、不加宽主干。
- 实现（PointRend，Kirillov et al., CVPR 2020）：`block.PointRefineHead`，13,072 个参数。
  - 每个点的输入：粗 logits（K）、decoder 最后一级特征的双线性插值（16）、原分辨率 CT 上 5×5 的强度块（步长为 512 画布上的一个像素），经过逐点 MLP（64 – 64 – 64 – K）。
  - 训练：每张图从 3×2048 个随机点中取不确定度最高的 75%，再补 25% 均匀随机点；在 512 画布标签上用交叉熵监督，与主损失等权。`RandomGenerator(hr_size=512)` 额外返回增强后的 512 画布图像和标签（图像线性插值，标签最近邻）。
  - 推理：粗 logits 双线性放大到原分辨率，重新判断不确定度最高的 8192 × 面积 / 512² 个像素。768² 的切片约 18k 个点（3.1%），5.2 ms，0.47 GFLOPs；512² 的切片约 0.21 GFLOPs，约为轻量档的 +3%。
  - 坐标统一用 align_corners=True，与 scipy zoom 一致：粗标签按最近邻取样，与原流程的最近邻放大 100% 相同；零偏移强度取样的误差 ≤2.4e-5。
- `test.py --upsample nearest|bilinear|refine`：带细化头的模型默认用 refine。为了把细化头本身和“双线性放大 logits”分开，标准增强基线的 3 个 seed 也会用 bilinear 测一次（`scratchpad/pr_evals.sh`，在 PR 跑完后自动执行），细化头模型再用 bilinear / nearest 测两次。
- 验证：默认路径逐位不变；AMOS 1 epoch 冒烟测试中训练速度与基线相同（2.5 分钟 / epoch），点损失从 2.79 降到 0.36。
- 排队：AMOS，标准增强，seed 1234。
- 结果（2026-10-22 22:55，refine 模式）：all15 80.51 / 12.17（标准增强基线 3 seed 80.42 ± 0.30 / 13.58 ± 1.65；同 seed 80.52 / 12.68），**synapse8 88.14 / 14.44**（基线 86.43；同 seed 86.61 / 15.55），IoU 70.65（同 seed 69.98），错误体积 **43.7 L**（同 seed 51.4 L，−15%），假阳性占比 41.4%（同 seed 48.1%）。点损失降到 0.034。

### 4.10 最终设计（2026-10-23 定）

- 模型：轻量档（R50 到 1/8 + LightViT-T + C = 64 精简 decoder，bottleneck 顺序为 post，§1.3），训练时加原分辨率点损失（`--point_loss`，推理时没有任何额外模块）。点损失在 AMOS 上 Dice 基本持平（§4.9），用 P2 对照在 3 个 seed 上确认。
- ApproxDA block 用一套与数据集无关的配置：
  - gate 固定为 ½（`--gate_mode fixed`）。workshop 中学到的 gate 一直在 0.5 左右；PAM 和 CAM 两支都保留。
  - r = 32，G = 8。
- M 按结构定义。PAM 的窗口边长会截到特征图大小（`M = min(self.M, H, W)`）。
  - local：取 1/8 特征图的边长，224 输入时为 28，256 输入时为 32。1/2 和 1/4 两层 skip 分窗口，1/8 skip 和 bottleneck 是全局。
  - global：取 1/2 特征图的边长（112 / 128），每一层都是全局。
  - 开销（轻量档，fixed gate）：M112 为 12.25M 参数 / 6.92 GFLOPs，M28 为 10.75M / 6.92 GFLOPs。FLOPs 不随 M 变化，参数差异全部来自 proj_r（M² · r）。
- 点损失扩展到所有数据集：CVC / ISIC（`_trainer_2d`）和 ACDC（`trainer_acdc`）的 RandomGenerator 加了 `hr_size`，在增强之后、缩放之前生成原分辨率标签。
  - 标签画布：Synapse / AMOS 为 512²，CVC 为 384²（原图 288×384），ISIC 为 256²，ACDC 为 224²。
  - ISIC 和 ACDC 的画布等于训练分辨率，点损失只相当于在不确定点上多加一次 CE。
  - 1 epoch 冒烟测试中 ACDC / CVC / ISIC 都正常退出。
- DA-TransUNet 加入 AMOS 支持：`dataset_amos.py`、`lists_AMOS`、NaN 指标、`[synapse8]` / `[all15]` 日志，训练用 `trainer_synapse`。DA 的 train.py 没有 `--run_tag`。

## 6. 代码参数（`experiments/ApproxDA-TransUNet/`，全部可选，默认逐位不变）
