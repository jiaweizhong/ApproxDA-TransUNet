## P1：与代码 / 协议不符

1. **压缩通道**：代码是 C′ = C / 16，不是 max(8, ⌊C / 16⌋)。实际 CAM 通道为 bottleneck 8、1/8 skip 32、1/4 skip 16、1/2 skip 4。
   两个分支各有一个 3×3 卷积（conv5a / conv5c），不是共用一个。
2. **融合**：conv8 是 Dropout2d(0.05) + 1×1 + ReLU，没有外层残差。
3. **CAM 分组**：代码取“不超过 G 且能整除通道数的最大组数”。G = 8 时，bottleneck（8 通道）和 1/2 skip（4 通道）每组只有 1 个通道，CAM 退化为 (1 + β)·x。
   - 稿中“G = 8 加速 8 倍且与原版 CAM 相同”要删掉：CAM 的计算量本来就可以忽略，而且 G = 1 在 Synapse 上 +0.55（不显著）。
   - 应如实写出这一退化，并引用 G = 1 那一行。
4. **decoder**：
   - skip 是**相加**融合：x + ReduceBlock(skip)，再接 ReduceBlock（带 1×1 shortcut 的残差块），不是拼接加两个 3×3 卷积；
   - 只有 3 个 skip stage 是 64 通道，全分辨率那一级是 16 通道，没有 skip。
   - 图 2(c) 是对的，正文和图 1 的图注要跟着改。
5. **HD95 单位**：Synapse 用的是 TransUNet 的旧版指标（legacy，不带 spacing），单位是体素，不是 mm。只有 FeTA 是 mm。
   NaN 处理（真值缺失的类不计入）也只用于 FeTA，不适用于 Synapse。
6. **训练细节缺失**：
   - SGD（lr 0.01，momentum 0.9，wd 1e-4，batch 24）；各数据集的 epoch 数（Synapse / ACDC 300，FeTA 61，ISIC 50）；CVC 用 Adam 1e-3、500 epoch。
   - 预训练权重：R50 用 TransUNet 的 R50 权重，LightViT-T 用 ImageNet-1k 权重。
   - 输入尺寸。
7. **其他协议表述**：
   - ISIC 是皮损分割，不只是 melanoma；
   - 优化目标里删掉“no point sampling penalties”这类对已删除模块的描述；
   - 门控“learnable gate 塌缩到 ≈ 0.5”需要给出处（workshop 的 gate 分析），否则删掉。

## P1：讨论部分的证据范围

1. **α/γ 死锁**：
   - 证据（|dL/dα| ≈ 4e-6–4e-5，权重漂移 0.84–0.86，测试时关掉 α 只改变 ≤ 0.0002% 像素）来自 workshop 时期的模型（ViT-B，pam gate，M112，SGD），不是最终模型。
   - 在 Adam 下（CVC）attention 是被训练了的；CAM 的 β 在 Synapse、CVC 上也不为 0。
   - 记号不一致：方法里用 α / β，标题写 α / γ。
   - 建议：在最终模型的 checkpoint 上补测 α、β 和权重漂移（CPU 上几分钟），并把结论限定在 SGD 和 PAM 上。
   - Synapse 上 attn_off +0.21（p = 0.57）、DA 等价 −0.01、r = 0 +0.19，可以直接支持“attention 算子可以替换，block 的卷积路径才是关键”。
2. **左右对称 / 镜像增强**：
   - “87% 的错误在真值边界 2 mm 以内”与日志不符：日志说的是约 87% 为器官与背景之间的边界或范围错误。

3. **局限性**：“约 12% 的错误在器官上下端”找不到出处，要么补分析，要么删。

## P2：行文逻辑

1. **主张过强**：
   - “consistently outperforming DA-TransUNet”：单个数据集都不显著，只有 15 组配对的合并检验显著（10 / 15，p = 0.010）。应写成“在 1/10 参数下与 DA 相当或略优，合并检验 +0.37 个百分点”。
   - “+0.37%”应写成“+0.37 个百分点（pp）”。
2. **HD95 要如实写**：5 个数据集中有 4 个比 DA 差（FeTA p = 0.04；Synapse、ACDC、ISIC 不显著），只有 CVC 更好。正文目前只提了 CVC。
3. **叙事一致性**：标题和贡献 2 主打“dual-attention approximation”，但消融显示 attention 算子本身可以去掉（attn_off ≈ 基准）。建议的主线：
   - (1) 轻量架构在 1/10 参数、约 1/4 FLOPs 下与 DA 相当；
   - (2) block 必要（去掉后 −2.76，p = 0.008）；
   - (3) block 里的 attention 怎么近似都不掉点（精确全局、窗口内精确、低秩、只留卷积都相当），原因是 SGD 下 α = 0 死锁。
   这样贡献 2 和 4 就是同一个发现的两面。
4. **缺文献 baseline 表**：已决定 Synapse、ACDC、CVC、ISIC 引用文献值，稿中还没有。CVC 和 ISIC 的划分与文献不同，表注要写明。
5. **措辞**：减少营销式用词（slash、ultra-、engineered、synergistic、rigorous、“proving zero penalty”），改用平实表述。
   Related work 里“exponential memory consumption”应为二次（quadratic）。
